第二轮整改与使用说明

当前评级仍为「存在潜在风险」。本轮处理账号凭据绑定、附件与打印副本、WebView2 崩溃上报和远图授权。更新包独立签名暂缓。以下各节包含历史审计记录，当前行为以本节为准。

项目当前行为使用边界
本地数据库和附件客户端使用标准 SQLite 保存邮件，附件按文件缓存。设置页没有本地加密选项。拥有缓存目录读取权限的程序可能读取邮件正文及附件。邮箱凭据仍由 Windows 凭据管理器托管。
迁移邮件目录预检和复制共用账号目录识别逻辑。预检遇到无法确认的条目时保留迁移选项。迁移发现账号目录、邮件库或其内容含链接或 Windows 重解析点，或无法读取邮件库属性时，会报告路径并中止切换。迁移实现失败后继续使用原目录。目录中确实没有 mail.db 的普通子目录会被跳过。用户仍可明确选择直接使用目标目录。
端点变更与旧凭据Windows 凭据管理器的单个绑定条目同时保存端点指纹与密码组或刷新令牌。读取时比对当前账号及实际连接采用的配置快照。指纹包含邮箱、认证方式、OAuth 客户端、IMAP/SMTP 主机、端口、TLS 模式、用户名及独立发信凭据设置。新增账号或更改邮箱地址时，会检查目标邮箱已有的凭据绑定。普通读取兼容旧版 v1 指纹，并保留原条目，供共用 Windows 凭据库的旧版实例继续读取。后台轮换刷新令牌时再次核对绑定和旧令牌，保留原指纹。内存 Graph 令牌也按身份与端点确认命中。凭据实现使用早期未绑定凭据的账号需重新输入密码或完成 OAuth 授权。仅修改配置文件无法将已有绑定凭据转用到新端点。凭据读写在单个进程内串行。安装版与便携版同时写同一条目时仍有竞争窗口。能访问当前用户凭据库的其他程序仍可能读取凭据。
导出附件同目录独占创建临时文件，写入 Internet 区域标记 Zone.Identifier / ZoneId=3 后发布至用户选择的位置。覆盖失败时保留原目标，并尝试清除临时文件。单个和批量导出使用相同实现。导出与转发不支持备用数据流的介质不能完成受保护的附件导出。后续跨盘复制、压缩或使用其他程序保存可能移除标记。来源标记无法判断附件内容是否安全。
转发及打印副本新副本存入本地应用数据目录下的 forward-attachments、print-temp。启动时检查旧文件；转发副本选取超过 30 天且未被草稿、发件箱或模板引用的普通文件（引用的本地路径已不存在时跳过该项，仅遇其余解析错误才停止清理），导出转发副本同样写入 Internet 来源标记。受管打印页面保留 24 小时供外部浏览器异步读取。打印文件管理清理依赖应用再次运行。旧版本散落在系统临时目录中的副本、外部浏览器留下的缓存、打印机队列、用户另存文件不在自动清理范围内。
阅读器、远图与运行时应用建立 WebView2 环境时显式设置 IsCustomCrashReportingEnabled，按微软属性定义阻止 Windows 将该 WebView 的崩溃数据发往微软；应用未新增转储上传服务。远图仍默认拦截。创建阅读控件时优先通过 ICoreWebView2Environment10 启用 WebView2 InPrivate 模式隔离磁盘缓存与会话，若当前运行时不支持该接口或选项设置失败则回退为普通控件（不保证磁盘缓存隔离）。切换阅读文档时，只要旧页或新页允许远图，就撤销旧授权、通过 CookieManager::DeleteAllCookies() 清理 Cookie、关闭旧控件并使用独立控件，过期资源回调返回拒绝。在 WebResourceRequested 中移除可见的 Referer、Cookie、Authorization 头；无法检查或移除时阻止请求。 阅读器实现主动显示远图时，目标服务仍能看到 IP、时间和 URL 中的跟踪标识；同一封邮件内若同时包含多个远图资源，单页加载过程中的传输层状态仍受 WebView2 运行时调度控制；在回退到普通控件的旧版 WebView2 运行时环境下，浏览器磁盘缓存隔离能力受运行时版本限制。运行时更新、SmartScreen 信誉检查、Windows 自身诊断和外部浏览器受其各自策略控制；本地崩溃转储仍可能存在。Microsoft WebView2 属性说明
